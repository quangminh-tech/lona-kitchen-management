LONA V6 - Dashboard và chứng từ có biến

Mở bản HTML xem thử

Chọn Quản trị hệ thống, bấm Mở dashboard, vào Mẫu chứng từ.

  1. Chọn loại mẫu: điều chuyển, đề nghị xuất hoặc xuất sản xuất.
  2. Sửa tiêu đề, chèn {{company.name}}, {{warehouse.to}}, {{document.number}}...
  3. Đổi nhãn/độ rộng cột, thêm hoặc bỏ cột, sửa ô chữ ký; chọn A4 dọc/ngang.
  4. Bấm Xem trước, Tải PDF mẫu hoặc Lưu phiên bản mới.

Chạy đầy đủ cùng server

Giải nén source vào thư mục mới LONA_V6. Cần Node.js 22.12+ và .NET SDK 10. Chạy bash scripts/build-and-run.sh, tự đặt mật khẩu admin khi Terminal hỏi. Mở http://localhost:5080, đăng nhập admin.

Thực đơn tháng/năm → chốt bữa → tính kế hoạch → mua/nhận hoặc điều chuyển → tính lại → xuất sản xuất → chọn phiếu nguồn và phát hành chứng từ → tải PDF. Bản phát hành giữ mẫu và dữ liệu tại thời điểm đó.

Bản HTML chỉ xem/thử mẫu tại trình duyệt. Phát hành, lịch nền và kiểm kho cần .NET. Dữ liệu runtime là JSON; chưa kết nối PostgreSQL hoặc kế toán. Dùng dữ liệu mẫu để thử trước.
