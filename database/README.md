# PostgreSQL reference only
Chưa kết nối database trong V4. business-reference.sql là sơ đồ nghiệp vụ tham khảo từ phiên bản trước, không phải migration chạy được để thay JSON ngay. Cần đối chiếu mô hình tuần/JSON và bổ sung user/role/permissions, session version, audit; không tự import mật khẩu demo hoặc tệp identity vào SQL.
